# Pepe Invierte Dashboard

Dashboard estatico para explorar empresas mencionadas por Pepe Invierte, revisar evidencia por video y usar una calculadora manual de scorecard.

## Contenido publicado

- `index.html`: aplicacion estatica completa.
- `vercel.json`: configuracion minima para publicar en Vercel.

## Notas

Esta herramienta es educativa y de seguimiento. No es recomendacion financiera, no calcula precio objetivo y no descarga datos de mercado en tiempo real.
